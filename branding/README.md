# Branding

`default/` holds the built-in brand (huisstijl) that ships with Stats Collector:

- `theme.json`: colour tokens for light and dark mode, fonts, per-channel chart colours, corner radius and live wall colours.
- `logo.svg`, `logo-dark.svg`: neutral default logo for light and dark backgrounds.

Administrators change the brand in **Admin → Branding** (logo, favicon, colours, fonts, chart colours). The result applies to the app, PDF reports, interactive reports, emails and the live wall. A brand can be exported as a file and committed here as a new folder, e.g. `branding/<customer>/`.
